# Agent第二大脑

> [!important] 唯一总入口
> 从这里进库，没有第二个首页。

这是一个**空骨架**。产品是这套循环，不是一座装满的库：

1. **自进化**——每天封账、蒸馏。定时器默认开着。需要一个模型：在 [[90 系统文件/自动化/自进化钥匙]] 写一行 `*_API_KEY`，或者本机已经登录过一个 AI 编程工具（claude、Codex、grok……）。两样都没有时，`status` 会一直提示 `host_action`，agent 必须告诉你。
2. **两步晋升**——五道门当天都过了，自动写成 `provisional`（准经验）；下次同类任务先问你；你采纳、那次任务也验收了，才升为 `active`。
3. **纠错优先**——纠错页比旧笔记说了算。
4. **检索锁**——一个短名词锁定一页，附 SHA 回执；不给隔壁页，不用向量库。

见 [[02 经验与方法/准经验/准经验入口|准经验入口]] 和仓库里的 `PROTOCOL.md`。
