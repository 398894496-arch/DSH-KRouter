# 日更健康

> 健康状态以这一页为准。

装好默认是 `lamp: running`，定时器开着。在 [[自进化钥匙]] 写一行 `*_API_KEY`，或者登录一次 `grok` / 官方 Codex / `claude`。两样都没有时不会蒸馏。`lamp: unused` 表示你把定时器关了。

`self_evolution_key` 或 `krouter_writer` 是 `missing` 时，`status` 会打印 `host_action`，挂着的 agent 必须告诉你。不要把 key 写在这一页。
