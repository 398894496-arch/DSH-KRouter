# 自进化钥匙

你的模型 key 放这里：贴在下面，或者把同样的一行写进 `~/.dsh-krouter-keys.env`。

贴在这里最省事：下一次运行时，key 会**自动挪出知识库**，存进 `~/.dsh-krouter-keys.env`（只有你能读，权限 600），这一行变成一句「已移到……」的说明。KRouter 只从那个文件读 key，从不从库里读——库里的东西写入工具读得到，库同步到哪里它就跟到哪里。KRouter 也从不把这一页发给模型，任何页面里的 key 都不会被打印（显示为 `<redacted>`）。

## 1. API key——自动锁定旗舰模型（优先）

去掉**其中一行**前面的 `# `，把占位符换成你的 key。写入器会列出这家厂商的模型目录，**自动锁定旗舰型号**，不会选 mini、haiku、flash-lite 这类小模型。之后它每天蒸馏，五道门通过时当天写准经验。

可选：写 `MODEL=` 自己指定型号。

```env
# DEEPSEEK_API_KEY=YOUR_DEEPSEEK_API_KEY
# OPENAI_API_KEY=YOUR_OPENAI_API_KEY
# ANTHROPIC_API_KEY=YOUR_ANTHROPIC_API_KEY
# XAI_API_KEY=YOUR_XAI_API_KEY
# GEMINI_API_KEY=YOUR_GEMINI_API_KEY
# GROQ_API_KEY=YOUR_GROQ_API_KEY
# OPENROUTER_API_KEY=YOUR_OPENROUTER_API_KEY
# MOONSHOT_API_KEY=YOUR_MOONSHOT_API_KEY
# DASHSCOPE_API_KEY=YOUR_DASHSCOPE_API_KEY
# OPENAI_BASE_URL=
# MODEL=
```

## 2. 没有 key——用你已有的订阅

如果这台电脑上已经登录过一个 AI 编程工具（命令行版），它会被自动找到并拿来做同样的事，库就是它的工作目录。

自动识别：`grok`、官方 Codex、`claude`、`cursor-agent`、`opencode`、`kimi`、`pi`、`vibe`、`antigravity`。PATH 里叫 `agent` 的程序会被拒绝。只在聊天网页或编辑器里登录、没有命令行的，不算。

健康页（`日更健康.md`）只记 `present` / `missing` / `dead`，绝不记 key 本身。
