# 准经验入口

新方法先进这里，不要让它们成为没人管的候选，也不要当正式方法用。

1. 五道门当天都通过 → **自动**写成 `status: provisional`。不用问，不用等。
2. 下次同类任务：问要不要采纳这份草稿。
3. 你采纳、这次任务也验收了 → 正式 `active`。
4. 被拒或没验收 → 保持准经验，或标 `rejected`。

「不自动晋升」说的是第 3 步不自动；第 1 步在五道门通过时是自动的。

准经验是可以拿来问的草稿，不是生产规则。

自带的示例：[[02 经验与方法/准经验/定时器响了不等于活干完了]]。有了你自己的准经验以后把它删掉。
