# Cloud infrastructure changes

All cloud resources are managed in Terraform; changes made in the console are reverted by the nightly drift check. A Terraform plan needs one review from the platform team. Changed after an undocumented console change caused an outage. This replaces [[Cloud infrastructure changes (old)]].
