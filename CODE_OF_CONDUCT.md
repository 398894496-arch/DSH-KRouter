# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be specific, be kind, assume good faith. Criticism of the work is welcome and has repeatedly made it
better (see `CHANGELOG.md`); criticism of people is not. Report unacceptable behavior privately through
GitHub (**Security → Report a vulnerability** works for this too) and it will be handled confidentially.
