# Provisional index

New methods enter here first. Do not leave them as orphan candidates. Do not treat them as formal methods.

1. Five gates pass the same day → **automatically** write `status: provisional`. Do not ask. Do not wait.
2. Next similar task: ask whether to adopt this draft.
3. Host adopts and this task is accepted → formal `active`.
4. Rejected or not accepted → stay provisional, or `rejected`.

“Do not auto-promote” means step 3 is not automatic. Step 1 is automatic when the gates pass.

Provisional is a draft you may ask about. It is not a production rule.
