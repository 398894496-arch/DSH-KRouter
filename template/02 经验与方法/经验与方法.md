# Methods

This folder answers only what to do next time. Only verified methods enter this folder. Candidates stay in projects or materials.

## Promotion

Meet all five the same day, then write [[02 经验与方法/准经验/准经验入口|provisional]]. Do not treat it as a formal method yet:

1. Comes from a real project or problem.
2. Has a result, evidence, or a same-day correction.
3. De-duplicated against existing methods.
4. States conditions and limits.
5. Lowers judgment or execution cost next time.

Promote to formal: on the next similar task, ask whether to adopt; the host adopts and that task is accepted. Otherwise stay provisional or mark `rejected`.
